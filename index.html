🌱 1. Ukuvula – Environment Setup (Windows)

Install WSL2 + Ubuntu:

Click here: Install WSL2

If the link doesn't work, copy and paste this into your browser:

https://learn.microsoft.com/en-us/windows/wsl/install

OR install manually:

  1. Press Windows key, type "powershell"
  2. Right-click "Windows PowerShell" → "Run as administrator"
  3. Copy and paste this command, press Enter:
wsl --install
  1. Restart your computer when it finishes
  2. After restart, search for "Ubuntu" and open it
  3. Create a username and password when asked
  4. Run this to update:
sudo apt update && sudo apt upgrade -y

Essentials:

  • Git for Windows
  • Visual Studio Code
  • Install the WSL extension in VS Code
